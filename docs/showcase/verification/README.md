[evidence-sha256.json](evidence-sha256.json) maps every copied data file to its repository-relative original path, original SHA256, distributed SHA256 and purpose. Copied bytes are identical to their original. `native/timing-extract.json.txt` is explicitly marked as a derived extraction, with its own source hashes and method. Original ignored paths are retained for audit context; they are not required to read these distributed copies. Primary JSON snapshots use `.json.txt` so repository format-on-commit tooling cannot rewrite their original bytes. Authored metadata remains ordinary JSON. Checksums detect alteration; they are not signatures or independent trust attestations.
